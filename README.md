# Hyper3-CLIP project page

Static project page for **Hyper3-CLIP: Hierarchy-Conditioned Hyperbolic
Vision-Language Training**, presented at the ECCV 2026 Beyond Euclidean
Workshop.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
